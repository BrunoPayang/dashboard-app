## 🔐 Connexion

### Comment se connecter
1. **Ouvrez votre navigateur** (Chrome, Firefox, Edge, Safari)
2. **Tapez l'adresse** de votre école dans la barre d'adresse
3. **Saisissez vos identifiants** :
   - Nom d'utilisateur
   - Mot de passe
4. **Cliquez sur "Se connecter"**

### Que faire si vous ne pouvez pas vous connecter
- ✅ Vérifiez que votre nom d'utilisateur est correct
- ✅ Vérifiez que votre mot de passe est correct (attention aux majuscules/minuscules)
- ✅ Contactez l'administrateur de votre école pour obtenir vos identifiants

## 👥 Gestion des Étudiants

### Voir la Liste des Étudiants
1. **Cliquez sur "Étudiants"** dans le menu
2. **Parcourez la liste** ou utilisez la barre de recherche
3. **Filtrez par classe, année, etc.** (si disponible)

### Ajouter un Nouvel Étudiant
1. **Cliquez sur "Créer un Étudiant"**
2. **Remplissez les informations** :
   - Nom et prénom
   - Date de naissance
   - Classe
   - Informations de contact
   - Photo (optionnel)
3. **Cliquez sur "Enregistrer"**

### Modifier un Étudiant
1. **Trouvez l'étudiant** dans la liste
2. **Cliquez sur son nom** ou sur l'icône "modifier" (crayon)
3. **Modifiez les informations** nécessaires
4. **Cliquez sur "Enregistrer"**

### Voir le Profil Complet d'un Étudiant
1. **Cliquez sur le nom de l'étudiant**
2. **Consultez** :
   - Informations personnelles
   - Historique académique
   - Paiements
   - Documents associés

### Supprimer un Étudiant
⚠️ **Attention : Cette action est irréversible !**
1. **Sélectionnez l'étudiant**
2. **Cliquez sur "Supprimer"** (icône poubelle)
3. **Confirmez la suppression**

## 📚 Dossiers Académiques

### Créer un Relevé de Notes
1. **Cliquez sur "Académique"**
2. **Sélectionnez l'onglet "Relevés de Notes"**
3. **Cliquez sur "Créer un Relevé"**
4. **Remplissez** :
   - ✅ **Étudiant** : Sélectionnez dans la liste déroulante
   - ✅ **Année académique** : (ex: 2024-2025)
   - ✅ **Semestre** : Premier, Deuxième, ou Rapport Annuel
   - ✅ **Moyenne** : Note sur 20 (ex: 15.50)
   - ✅ **Fichier** : Choisissez un document PDF préalablement téléchargé
   - ✅ **Notes** : Commentaires additionnels (optionnel)
5. **Cliquez sur "Enregistrer"**

### 📋 Important pour les Relevés de Notes
- **Moyenne** : Utilisez l'échelle française de 0.00 à 20.00
- **Fichier** : Le document doit être téléchargé dans la section "Fichiers" avant de pouvoir le sélectionner
- **Format** : Privilégiez le format PDF pour les relevés

### Créer un Rapport de Comportement
1. **Dans "Académique"**, cliquez sur l'onglet **"Rapports de Comportement"**
2. **Cliquez sur "Créer un Rapport"**
3. **Saisissez** :
   - Étudiant concerné
   - Date de l'incident/observation
   - Description détaillée
   - Actions prises
   - Recommandations
4. **Enregistrez**

### Consulter l'Historique Académique
1. **Ouvrez le profil d'un étudiant**
2. **Consultez** :
   - Tous les relevés de notes
   - Rapports de comportement
   - Évolution des performances

## 🔔 Notifications

### Envoyer une Notification
1. **Cliquez sur "Notifications"**
2. **Cliquez sur "Nouvelle Notification"**
3. **Rédigez** :
   - Objet du message
   - Contenu du message
   - Destinataires (parents, étudiants, personnel)
4. **Choisissez le mode d'envoi** :
   - Notification dans l'application
   - Email (si configuré)
   - SMS (si disponible)
5. **Envoyez**

### Types de Notifications
- 📢 **Annonces générales** (événements, fermetures, etc.)
- 📝 **Messages individuels** (convocations, félicitations)
- 💰 **Rappels de paiement**
- 📊 **Notifications de relevés** (nouvelles notes disponibles)

### Programmer une Notification
1. **Créez votre message**
2. **Cochez "Programmer l'envoi"**
3. **Choisissez la date et l'heure**
4. **Confirmez**

## 🚨 Résolution de Problèmes

### Problèmes Courants

#### ❌ "Je ne peux pas me connecter"
**Solutions** :
1. Vérifiez votre nom d'utilisateur et mot de passe
2. Effacez le cache de votre navigateur
3. Contactez l'administrateur

#### ❌ "La page ne charge pas"
**Solutions** :
1. Actualisez la page (F5)
2. Vérifiez votre connexion Internet
3. Essayez un autre navigateur

#### ❌ "Je ne peux pas télécharger de fichier"
**Solutions** :
1. Vérifiez que le fichier fait moins de 10 MB
2. Utilisez un format supporté (PDF, JPG, PNG, DOC)
3. Essayez avec un autre fichier

#### ❌ "Erreur lors de la création d'un relevé de notes"
**Solutions** :
1. Vérifiez que tous les champs requis sont remplis
2. Assurez-vous que la moyenne est entre 0.00 et 20.00
3. Vérifiez qu'un fichier est sélectionné
4. Contactez le support si le problème persiste

#### ❌ "Les notifications ne partent pas"
**Solutions** :
1. Vérifiez les adresses email des destinataires
2. Contactez l'administrateur pour vérifier la configuration
3. Essayez d'envoyer à un seul destinataire test
